# 애니위키 키트 (anywiki-kit)

누구나 자기 컴퓨터나 서버에 **나만의 위키([openNAMU](https://github.com/openNAMU/openNAMU))** 를 원터치로 띄울 수 있게 해 주는 도구입니다.
**누구의 서버도 필요 없습니다.** 키트는 공식 배포처에서 프로그램을 받아 해시로 검증할 뿐, 제작자는 서버를 운영하지 않습니다.

> [유어위키](https://github.com/iamtalker/yourwiki)(나무위키 전체를 내 컴퓨터에 보존)에서 나무위키 전용 기능(데이터·동기화·P2P)을 뺀 범용판입니다.
> 유어위키와 **같은 컴퓨터에서 함께 켤 수 있도록** 주소(포트)를 달리 씁니다: 관리판 `4100`, 위키 `4000`(유어위키는 `3100`·`3000`).

## 주요 기능

- **원터치 설치·켜기·끄기**: `애니위키.exe`를 실행해 관리판에서 [설치] → [켜기]만 누르면 openNAMU 위키가 뜹니다(파이썬은 처음 한 번만 받습니다, 약 20MB).
- **빈 위키에서 시작**: 문서를 직접 쓰고 고치는 진짜 위키입니다. 처음 가입한 사람이 관리자가 됩니다.
- **내보내기**: 위키의 모든 문서를 **openNAMU · MediaWiki · DokuWiki · Markdown** 형식으로 내보냅니다. 문법을 자동으로 통역합니다(제목·표·각주·목차·분류·틀 호출 등).
- **가져오기**: openNAMU 형식(`.db`) 파일을 가져옵니다. 문서마다 내 쪽보다 새 판만 이어 붙입니다(유어위키가 내보낸 파일도 됩니다).
- **오프라인 동작**: 설치 후에는 인터넷 없이 되고, 원래 CDN에서 불러오던 파일은 동봉한 것으로 바꿔 씁니다.
- **인터넷에 공개**: 관리판의 [공개하기]로 공유기 설정 없이 임시 주소를 만들 수 있습니다. 공개하는 순간 운영 책임은 공개한 사람에게 있습니다.
- **보기 좋게**: 머리글 색 고르기, 휴대폰 화면, 검색 자동완성을 붙였습니다.
- **새 판 알림**: 12시간에 한 번 최신 릴리스만 확인해 알려 줍니다(스스로 설치하지 않습니다. 끌 수 있습니다).
- **서버 설치**: 리눅스 스크립트와 Docker를 지원합니다.

**알아 둘 점**: 이미지 파일은 내보낼 때 옮기지 않습니다. 틀(템플릿)의 내용은 엔진마다 달라 손으로 고쳐야 할 수 있습니다.

## 써 보기 (Windows)

1. [릴리스](https://github.com/iamtalker/anywiki-kit/releases/latest)에서 `anywiki-kit-….zip`을 받아 풉니다.
2. 폴더 안의 **`애니위키.exe`**를 더블클릭합니다. 관리판이 열리면 **[설치]** → **[켜기]** → **[위키 열기]**.
   Windows가 "알 수 없는 게시자"라고 경고하면 [추가 정보] → [실행]을 누르세요(서명하지 않은 개인 프로그램이라 나오는 경고입니다).

풀면 최상위에는 이것만 있습니다.

| 이름 | 하는 일 |
|---|---|
| `애니위키.exe` | 실행 파일 |
| `서버설치가이드.html` | 리눅스 서버에 올릴 때의 안내(웹 페이지) |
| `kit/` | 프로그램·도구·설정이 모두 든 폴더 |
| `wikis/` | (설치하면 생김) 내 위키 데이터. 옮기거나 백업할 때는 이 폴더만 |

## 설치와 새 판으로 올리기

**처음 설치**: 위 「써 보기」대로 하면 됩니다.

**새 판으로 올리기(0.7 이상)** — 위키 데이터는 그대로 두고 프로그램만 새 것으로 바꿉니다.
1. 위키를 끕니다(관리판의 **[끄기]**를 누른 뒤 관리판 창을 닫으세요).
2. 새 압축 파일을 **지금 쓰는 폴더에 그대로 풀고 "덮어쓰기"**를 고릅니다. (`애니위키.exe`가 열려 있으면 먼저 닫으세요.)
3. `애니위키.exe`를 다시 실행합니다. 끝입니다.

압축 파일에는 `wikis` 폴더와 설정·받아 둔 도구가 들어 있지 않아서, **`wikis` 폴더(내 위키)와 설정은 건드려지지 않습니다.**
새 판에서 무엇이 달라졌는지는 [kit/CHANGELOG.md](kit/CHANGELOG.md) 맨 위에 있습니다.
**0.6 이하에서 올라올 때만** 폴더 구조가 달라서 덮어쓰면 안 됩니다. 새 폴더에 풀고, 옛 폴더의 `wikis` 폴더만 새 폴더의 `애니위키.exe` 옆으로 옮기세요.
