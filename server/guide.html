애니위키 서버 설치 가이드

인터넷에 공개하는 서버(보통 리눅스 VPS)에 애니위키를 올리는 방법입니다. 내 PC에서만 쓸 거라면 애니위키.bat으로 충분합니다.

공개하는 순간 그 사이트의 운영 책임(권리 침해·게시중단 요청 대응 등)은 공개한 사람에게 있습니다.

1. 준비물

  • 리눅스 서버 (Ubuntu 22.04 이상 권장, 64비트 x86 또는 ARM)
  • 디스크 1GB 이상(문서가 늘어나는 만큼 더), 메모리 1GB 이상
  • 서버에 SSH 로 접속할 수 있는 상태

2. 필요한 프로그램 설치 (Ubuntu/Debian)

sudo apt update && sudo apt install -y git python3 curl

3. 키트 받기

git clone https://github.com/iamtalker/anywiki-kit && cd anywiki-kit

4. 설치 (몇 분)

bash server/install.sh

위키 엔진(openNAMU)을 받아 해시를 검증하고 빈 위키와 첫 화면을 만듭니다.

5. 켜기

bash server/anywiki.sh start

브라우저로 http://서버주소:4000 에 접속합니다.

6. 부팅할 때 자동으로 켜기 (선택)

sudo bash server/anywiki.sh install-service

7. 자주 쓰는 명령

bash server/anywiki.sh status
bash server/anywiki.sh stop
LISTEN=127.0.0.1:4000 bash server/anywiki.sh start
TUNNEL=on bash server/anywiki.sh start
bash server/anywiki.sh export markdown

LISTEN: 받을 주소(기본 0.0.0.0:4000 = 외부 공개). TUNNEL=on: 공인 IP 없이 Cloudflare 임시 주소(https)로 공개(주소는 status 로 확인, 켤 때마다 바뀜). 한 번 준 값은 anywiki.conf 에 기억되어 다음부터 그냥 start 해도 그대로입니다. export: export/ 에 내보내기.

8. 공개 전에 할 일

  1. 관리자 계정: openNAMU 는 위키에서 처음 가입한 사람이 관리자가 됩니다(켜자마자 먼저 가입).
  2. 편집 권한: 관리자 설정에서 누구나 / 가입자만 / 읽기 전용 중에서 정하세요.
  3. HTTPS: nginx 나 Caddy 를 4000번 앞에 두면 됩니다. 예) Caddy: reverse_proxy 127.0.0.1:4000
  4. 방화벽: 4000번(또는 80/443) 포트를 여세요.
  5. 연락처: 삭제·권리 침해 요청을 받을 연락처를 위키에 적어 두세요.

이 스크립트들은 베타입니다. 문제가 있으면 https://github.com/iamtalker/anywiki-kit 에 이슈로 알려 주세요.
